This build deliberately follows the approved generated reference composition rather than redesigning it.
Because the reference contains photoreal AI-rendered jewellery, pure HTML/CSS cannot reproduce those photographic pixels as live DOM elements. The build recreates layout, palette, typography, spacing, hierarchy and motion, and includes the exact approved reference image for visual comparison.
For literal photographic parity, the jewellery photography/3D renders need to be used as image assets.
